MASOOLI GARDEN DEPOT — CLOUD MOBILE SYSTEM

Connected Supabase project:
- Masooli Garden Depot
- Owner/admin and worker role separation
- Row Level Security
- Realtime updates
- Stock issue, sales, returns, purchases and adjustments
- Worker settlements/payments
- Daily/monthly reporting
- Audit-friendly transaction ledger
- Worker-specific privacy
- Offline worker sales queue with idempotent sync when internet returns

Owner can see:
warehouse stock, buying prices, selling prices, purchases, workers, worker sales, settlements, outstanding balances, commission and reports.

Worker can see:
only their issued stock, sales, expected amount, payments/outstanding balance, commission and personal history.

Never place a Supabase service-role/secret key in this browser app.
